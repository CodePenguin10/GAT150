This game's title is "Some Sprite Game IG"


"Some Sprite Game IG" is a very simple platformer/rpg, where you control a very simple character fighting against an endless wave of enemies. Your goal is to survive for as long as possible and get as high of a score as you can.


How to control:

 • A and D to move left and right
 
 • Space to jump
 
 • Right shift to attack
 
 • Space when on the title screen to start


Features this game has:

 • 2 different enemies (one grounded and one aerial)
 
 • Custom art for the hero and flying enemy
 
 • Moveable crates


How to build:

 • Download the code into a zip file
 
 • Open it in Visual Studio 2022
 
 • It should build and run from there
 

Problems:

 • Grounded enemies have no gravity and cannot detect anything, being immortal whilst also ignoring the player's existence
 
 • Game has a chance of crashing when the hero dies and they attacked shortly before or after death.
 
 • Lack of additions
 

Additional libraries:

 • SDL3 (https://wiki.libsdl.org/SDL3/FrontPage)
 
 • SDL3_image (https://wiki.libsdl.org/SDL3_image/FrontPage)
 
 • RapidJSON (https://rapidjson.org/)
 
 • FMOD (https://www.fmod.com/)
 
 • Box2D (https://box2d.org/)
